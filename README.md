# Harshal Hattyangdi Portfolio

Single-page portfolio built with Astro, TypeScript and plain CSS.

## Run locally

```bash
nvm use
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- The site is fully static and suitable for Netlify deployment.
- The project targets Node `22.22.2` via `.nvmrc` and `netlify.toml`.
- `public/Harshal-Hattyangdi-CV.pdf` is a placeholder PDF and should be replaced with the latest CV.
